論文を読む (DP)

← 一覧へ

Mac 側で PDF 取得 → 図表切り出し → agent 生成が走る（10〜20 分）。 このページは閉じてよい。完成すると 一覧 の先頭に出る。

URL を貼って読む（arXiv abs/pdf、OpenReview、PMLR、JMLR、ACL、NeurIPS、*.pdf）

iPad / iPhone のブラウザからポチッと起動する設定

1. ブックマークレット（Chrome / Safari 共通・いちばん手軽）

論文ページで下のブックマークを開くと、このページに URL を持って飛んでくる。あとは「この論文を読む」を 1 タップ。

javascript:(function(){location.href="__ORIGIN__/go?url="+encodeURIComponent(location.href)})()
  1. 任意のページをブックマークに追加（名前は「DPで読む」等）。
  2. ブックマークを編集し、URL 欄を上のコードに置き換える。
  3. 論文ページを開いた状態でそのブックマークを開く。
    Chrome for iPad でブックマーク一覧からの実行が効かない場合は、アドレスバーにブックマーク名を打って候補から選ぶと実行される。

2. 共有シート（iOS ショートカット・完全 1 タップ）

ショートカット app で「共有シートに表示」する 1 本を作る。Safari / Chrome の「共有」→「DPで読む」で即起動、結果が通知で出る。

  1. ショートカット app → 「＋」→ 名前「DPで読む」。
  2. 右上の情報アイコン → 「共有シートに表示」を ON、「受け取る種類」を URL だけにする。
  3. アクション「URL の内容を取得」を追加:
    • URL: __ORIGIN__/api/readpaper
    • 方法: POST、本文: JSON
    • フィールド url = 「ショートカットの入力」、フィールド token = 下のトークン
  4. アクション「通知を表示」を追加し、本文に「URL の内容」を入れる。
__TOKEN__

トークンは Mac の ~/Library/Application Support/readpaper/config.env の ASK_TOKEN。 変えたらショートカット側も更新する。

3. 知っておくこと

iPad からは URL だけが Mac に届く。Mac の Chrome 拡張と違ってブラウザの cookie で PDF を取れないので、 ログインや bot 壁（OpenReview の Turnstile 等）の向こうにある PDF は落とせず、Mac 側で「download failed」になる。 arXiv / PMLR / JMLR / ACL / NeurIPS など素で取れる会場は問題ない。
同じ論文の解説が既にある場合は生成せず、その解説へのリンクを返す（Mac の重複ガードと同じ判定）。
Tailscale が ON で、Mac が起きていること。この URL（__ORIGIN__）は Tailnet の中からしか届かない。
